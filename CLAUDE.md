# Kenneth Turner portfolio site

This is a static GitHub Pages site. Content lives in `data/portfolio.json`, and `js/portfolio.js` renders it. A push to `main` deploys the site. Every committed file is published, including this one.

Keep this file public-safe: no private sources, local paths, internal metrics, or unverified details. Private guidance loads from `CLAUDE.local.md`, which is never committed. If that file is missing, ask Kenneth before editing site content.

## Content rules

- Present product, program, and portfolio leadership.
- The enterprise experience stands on its own. The Enterprise AI Blueprint is a supporting theme.
- Describe ownership project by project, and name what other teams owned. Avoid blanket claims like "owned end to end."
- Keep Kenneth's decisions separate from engineers' technical design work.
- Don't invent metrics, outcomes, or reasoning. Label prototypes as prototypes.
- Don't commit, push, merge, or deploy without Kenneth's approval.
